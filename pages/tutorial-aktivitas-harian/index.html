📘 Tutorial: Halaman Aktivitas Harian & Penyimpanan ke Google Sheets

Tutorial ini menjelaskan cara kerja satu halaman aktivitas harian di HAXcms: bagaimana membaca materi, mengunduh file, berdiskusi di forum, mengumpulkan tugas, dan mengerjakan kuis formatif — semuanya tercatat otomatis ke Google Sheets melalui dua endpoint Google Apps Script.

1️⃣ Alur Aktivitas Harian

  1. Login (sekali, 24 jam) — siswa login dengan NIS + email lewat quiz-user-auth. Session tersimpan di localStorage (kunci quiz_user_session) dan dipakai semua komponen di halaman ini.
  2. Baca materi — scroll halaman > 1000px otomatis dicatat sebagai aktivitas reading (jeda minimal 2 menit antar catatan).
  3. Download materi — klik link <a href="files/..." download> dicatat sebagai aktivitas download.
  4. Diskusi/komentar — komentar di forum-component tersimpan ke sheet Forum Log + dicatat sebagai aktivitas discussion.
  5. Tugas — pengumpulan di assignment-component tersimpan ke sheet Tugas Log + dicatat sebagai aktivitas assignment.
  6. Kuis formatif — skor tersimpan ke sheet pertemuan-kuis + dicatat sebagai aktivitas quiz.
  7. Cek status — attendance-tracker & engagement-score menampilkan ringkasan harian + heatmap 42 hari sesuai akun yang login.

5️⃣ Deploy Kedua Endpoint Apps Script

Kode backend sudah tersedia di repositori: custom/src/quiz-dashboard-lite2/lib/code.gs (utama) dan custom/src/quiz-dashboard-lite2/lib/code-forum-tugas.gs (forum & tugas).

  1. Buka script.google.com → buat proyek baru → salin isi code.gs → simpan.
  2. Deploy → New deployment → jenis Web app:
    • Execute as: Me
    • Who has access: Anyone
  3. Salin URL /exec → itu Apps Script utama (kuis/aktivitas/login).
  4. Ulangi dengan isi code-forum-tugas.gs → URL kedua = Apps Script forum & tugas.
  5. Pastikan spreadsheet tujuan sudah dibagikan (viewer) ke email akun yang menjalankan script.

Action yang didukung backend utama: login, register, verify, submit, logActivity, getActivityHistory, getScores, getBankSoal, dll. Backend forum: saveForumComment, deleteForumComment, saveAssignment, getForumComments, getForumActivityHistory.

7️⃣ Kriteria Status LENGKAP (100%)

attendance-tracker menghitung 6 kriteria harian:

  • 📖 Membaca materi: minimal 3× (tipe reading)
  • 🎯 Mengerjakan kuis: minimal 1× (tipe quiz)
  • 📝 Mengumpulkan tugas: minimal 1× (tipe assignment)
  • ⬇️ Download materi: minimal 1× (tipe download)
  • 💬 Komentar forum: minimal 1× (dari sheet Forum Log, bukan localStorage)
  • 🔥 Total aktivitas harian: minimal 8×

🔟 Satu Materi = Satu Forum (Per Pertemuan)

Setiap materi/pertemuan bisa punya forum sendiri tanpa membuat spreadsheet atau URL Apps Script baru. Caranya: semua komentar tetap masuk ke satu sheet Forum Log, dan kolom kdMateri yang memisahkan forum antar pertemuan.

kdMateri otomatis sama dengan atribut sheet-name pada tag. Backend memfilter di dua titik:

  • getForumComments → menampilkan di halaman hanya komentar yang kolom kdMateri-nya sama dengan sheet-name halaman itu.
  • getForumActivityHistory → menghitung kriteria "💬 Komentar forum" di tracker hanya untuk kdMateri yang sama.

PENTING: filter bersifat exact match (persis sama). Pertemuan-1 ≠ Pertemuan 1; spasi, tanda hubung, dan huruf kapital membuat forum terlihat berbeda.

Halamansheet-name (harus sama di semua tag)Forum yang tampil & terhitung
Materi Pertemuan 1Pertemuan-1Hanya komentar kdMateri = Pertemuan-1
Materi Pertemuan 2Pertemuan-2Hanya komentar kdMateri = Pertemuan-2

Contoh Halaman Pertemuan-1

<attendance-tracker apps-script-url="..." forum-api-url="..." sheet-name="Pertemuan-1"></attendance-tracker>
<engagement-score apps-script-url="..." forum-api-url="..." sheet-name="Pertemuan-1"></engagement-score>
<forum-component apps-script-url="..." forum-api-url="..." sheet-name="Pertemuan-1" forum-topic="Diskusi Pertemuan 1"></forum-component>
<assignment-component apps-script-url="..." forum-api-url="..." sheet-name="Pertemuan-1" assignment-title="Tugas Pertemuan 1"></assignment-component>
<activity-logger apps-script-url="..." forum-api-url="..." sheet-name="Pertemuan-1"></activity-logger>
<explode-quiz apps-script-url="..." sheet-name="Pertemuan-1" quiz-category="formatif">...</explode-quiz>

Untuk Halaman Pertemuan-2: ganti semua sheet-name="Pertemuan-1" menjadi sheet-name="Pertemuan-2" (dan forum-topic/assignment-title sesuai materi). Komponen lain tetap identik.

Data lama yang tidak muncul

Komentar lama yang kolom kdMateri-nya kosong tidak akan tampil maupun terhitung (contoh: baris 26/07–01/08 dengan Sheet = "Pertemuan 1"). Untuk menampilkannya kembali: isi manual kolom kdMateri pada baris tersebut di spreadsheet — nilainya harus sama persis dengan sheet-name halaman (mis. Pertemuan-1). Baris tanpa StudentID tidak akan terhitung siapa pun.

Setelah mengubah file backend (.gs)

  1. Salin ulang isi code.gs / code-forum-tugas.gs dari repositori ke proyek Apps Script masing-masing.
  2. Deploy → Manage deployments → ikon pensil (Edit) pada deployment Web App → Version: New version → Deploy.
  3. URL /exec tidak berubah, tetapi versi baru langsung aktif untuk panggilan berikutnya.
