📘 Panduan Guru: Soal, Nilai & Rapor

Panduan lengkap alur kerja: Materi → Kuis (Formatif/UH/UTS/UAS) → Sikap & Keterampilan → Bobot Nilai → Rapor. Semua data tersimpan di satu Google Spreadsheet lewat Apps Script.

🎯 Alur Kerja

  1. Siapkan 1 Spreadsheet + deploy Apps Script (code.gs) → dapatkan URL Web App
  2. Buat halaman Materi di HAXcms
  3. Siswa login & mengerjakan kuis (formatif, ulangan harian, UTS, UAS)
  4. Dosen: input nilai manual UTS/UAS + atur bobot 6 komponen
  5. Dosen: klik Generate Laporan Rapor → nilai akhir & grade otomatis
  6. Siswa melihat nilai di tab 📊 Daftar Skor

🚀 Langkah 1: Setup Spreadsheet + Apps Script

  1. Buka sheets.google.com → buat spreadsheet baru (nama: Course: HAXcms & Web Component).
  2. Klik Extensions → Apps Script, hapus kode default, lalu copy-paste seluruh isi code.gs (tersedia di custom/src/quiz-dashboard-lite2/lib/code.gs).
  3. Klik Save, lalu Deploy → New deployment → Web app (Execute as: Me; Access: Anyone).
  4. Salin Web app URL — ini yang dipakai sebagai apps-script-url di semua halaman.
🔗 URL Web App kuis yang aktif di situs ini:
https://script.google.com/macros/s/AKfycbzwwv-XI1EC3puQdS8rsTjOobw8rmNXOqOkklInfFB5xBdQJ83po2lq-gxRtDuiE5LG/exec

Apps Script otomatis membuat sheet tab per pertemuan: Pertemuan 1 - Kuis, Pertemuan 1 - Aktivitas, Rangkuman, Nilai Manual, Akumulasi Nilai Rapor. Buat tab Users untuk daftar siswa: Student ID | NIS | Nama | Absen | Kelas.

📚 Langkah 2: Buat Halaman Materi

  1. Di HAXcms, klik Edit Page lalu tambah halaman baru (tambah item di menu).
  2. Isi materi dengan blok teks, <media-image> (gambar), <video-player> (YouTube), dsb.
  3. Aktivitas membaca siswa (scroll) otomatis tercatat sebagai log reading — bahan untuk nilai keterampilan.

📝 Langkah 3: Kuis Formatif, Ulangan Harian, UTS, UAS

3a. Elemen kuis langsung di halaman

<explode-quiz
  apps-script-url="https://script.google.com/macros/s/AKfycbzwwv-XI1EC3puQdS8rsTjOobw8rmNXOqOkklInfFB5xBdQJ83po2lq-gxRtDuiE5LG/exec"

  quiz-category="formatif"

  shuffle-choices

AtributKegunaan
sheet-nameNama pertemuan → data masuk ke tab <nama> - Kuis. Ganti per kegiatan: "Pertemuan 1", "UTS", "UAS".
quiz-categoryformatif (latihan) atau sumatif (penilaian). Membedakan kolom skor di Rangkuman.
tagKode materi (UH1, UTS, UAS) untuk memisahkan nilai per jenis.
questionsJSON array soal — diisi otomatis saat Anda edit soal lewat tombol "✏️ Edit Soal".
editabletrue agar tombol edit soal muncul untuk pengunjung.

Membuat soal: buka halaman (mode dosen), klik tab 📝 Ambil Kuis → tombol ✏️ Edit Soal (atau langsung setelah klik Mulai) → tambah/edit soal per tipe → Tutup Editor → Save halaman di HAXcms agar tersimpan permanen.

3b. Skema soal (JSON)

TipeProperti yang wajib

shortAnswer — Isian Singkattype, question, acceptedAnswers[]

🗂️ Langkah 4: Bank Soal & Template (Generate Otomatis)

Buat tab Bank Soal di spreadsheet. Kolom: ID | Kategori | Tipe | Soal | Detail (JSON) | Gambar | Poin.

KolomIsi
IDNomor urut (opsional)
Kategoriliterasi, numerasi, atau campur
Tipemc, pgk, matching, shortAnswer
SoalTeks pertanyaan
DetailJSON properti (lihat contoh di bawah)
GambarURL gambar (opsional)
PoinBobot (default 1)
 
// Contoh isi kolom Detail per tipe
{"choices":["Jakarta","Bandung","Surabaya"],"correctIndex":0}
{"statements":[{"text":"Ide pokok ada di kalimat utama","answer":true},{"text":"Kata 'mengapa' menanyakan tempat","answer":false}]}
{"leftItems":["1+1","2+2"],"rightItems":["2","4"],"correctPairs":[["1+1","2"],["2+2","4"]]}
{"acceptedAnswers":["pancasila","Pancasila"]}

Cara pakai: buka halaman /kuis-akm-campuran → tab 🛠️ Console Dosen → klik ✨ Generate Soal Template Lokal (acak dari bank bawaan elemen) atau 🗂️ Generate Soal dari Bank Soal (baca tab Bank Soal via action getBankSoal). Soal langsung termuat ke kuis, lalu kerjakan di tab 📝 Ambil Kuis.

🧭 Langkah 5: Sikap & Keterampilan

Kedua nilai dihitung otomatis dari aktivitas siswa (tidak perlu diinput manual):

KomponenRumusMaks
Sikap(jumlah tugas × 25) + (jumlah komentar forum × 20)100
Keterampilan(jumlah kuis × 30) + (jumlah membaca × 10)100

Yang diinput manual oleh dosen hanyalah UTS dan UAS: di Console Dosen, isi kolom UTS Manual / UAS Manual per siswa (0–100) → tersimpan ke sheet Nilai Manual.

📊 Langkah 6: Bobot Nilai & Generate Rapor

  1. Buka halaman kuis → tab 🛠️ Console Dosen.
  2. Atur 6 bobot: Kehadiran, Ulangan Harian, UTS, UAS, Sikap, Keterampilan (nilai 0–10, mis. 1:3:2:2:0:0). Bobot tersimpan di browser (localStorage) dan dikirim saat generate.
  3. Klik 📊 Generate Laporan Rapor.

Rumus nilai akhir: (Kehadiran×bKehadiran + Rata-UH×bUH + UTS×bUTS + UAS×bUAS + Sikap×bSikap + Keterampilan×bKeterampilan) ÷ total bobot

Hasil ditulis ke sheet Akumulasi Nilai Rapor dengan kolom: Student ID, NIS, Nama, Absen, Kelas, Jumlah Pertemuan, Rata Aktivitas/Pertemuan, Kehadiran, Rata-rata UH, Skor UTS, Skor UAS, Skor Sikap, Skor Keterampilan, Nilai Akhir, Grade.

Siswa melihat nilai: buka halaman dashboard → tab 📊 Daftar Skor (mode siswa menampilkan gradebook transparan; nilai muncul setelah login).

🧰 Troubleshooting

GejalaSolusi
"Elemen kuis tidak ditemukan (pastikan selector benar)"Pastikan halaman memakai <quiz-dashboard-lite2> versi terbaru (kuis kini selalu dirender). Bila pakai elemen terpisah, pastikan ada <explode-quiz id="quiz">.
Soal hasil edit hilang setelah disimpanKlik Tutup Editor dulu (memicu simpan soal), lalu Save halaman di HAXcms. Atribut questions harus tertulis di halaman setelah reload.
Warning console "Import already in progress, skipping duplicate call"Jinak — race internal HAXcms saat simpan. Data tetap tersimpan; jika konten terlihat lama, refresh halaman.
"Apps Script URL belum dikonfigurasi"Isi apps-script-url dengan URL Web App di atas.
Sheet 'Bank Soal' belum adaBuat tab bernama persis Bank Soal dengan kolom ID|Kategori|Tipe|Soal|Detail|Gambar|Poin.
