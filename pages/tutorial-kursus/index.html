📅 Tutorial: Cara Menambah Kuis di Hari Lain untuk Kursus

Panduan ini menjelaskan bagaimana menyusun kursus multi-hari/multi-sesi di HAXcms, di mana setiap halaman materi memiliki kuis harian dan pelacakan aktivitas sendiri. Cocok untuk dosen/guru yang ingin membuat course terstruktur per pertemuan.

Google Sheets

🚀 Metode 1: Halaman Manual per Pertemuan (Direkomendasikan)

Buat satu halaman baru untuk setiap pertemuan. Setiap halaman punya materi sendiri, kuis sendiri, dan activity logger sendiri.

Langkah 1: Buat Halaman Baru via HAXcms Editor

  1. Buka HAXcms editor
  2. Klik Pages → Add Page di sidebar
  3. Beri judul sesuai pertemuan, contoh: "Pertemuan 2: Lit Element Dasar"
  4. Tentukan slug URL: pertemuan-2

Langkah 2: Isi Konten Materi

Tulis materi pembelajaran seperti biasa. Gunakan heading, paragraf, gambar, tabel, dll.

Langkah 3: Tambahkan Kuis di Akhir Halaman

Ada dua cara menambah kuis:

Cara A — Via Element Tray (Mudah)

  1. Klik Tambah Elemen (+) di panel kiri
  2. Cari "Explode Quiz"
  3. Klik atau seret ke posisi yang diinginkan di halaman

Cara B — Via Source Mode (Kontrol Penuh)

  1. Klik tombol Source di editor
  2. Paste tag berikut di posisi yang diinginkan:
<explode-quiz editable="false"></explode-quiz>
💡 Tips: editable="false" menyembunyikan tombol edit soal untuk siswa. Dosen tetap bisa edit soal saat membuka halaman di HAX Editor.

Langkah 4: Tambahkan Activity Logger

Di bagian paling bawah halaman (setelah semua konten), paste:

<activity-logger></activity-logger>

Ini akan mengaktifkan pelacakan scroll, klik link, download, dan kuis di halaman tersebut.

Langkah 5 (Opsional): Tambahkan Attendance Tracker

<attendance-tracker></attendance-tracker>
<engagement-score></engagement-score>

🚀 Metode 2: Dashboard Full Quiz (Satu Tag untuk Semua)

Gunakan <full-quiz-dashboard> untuk halaman yang langsung menyediakan kuis, attendance, heatmap, dan gradebook dalam satu komponen.

<full-quiz-dashboard apps-script-url="https://script.google.com/macros/s/YOUR_ID/exec"></full-quiz-dashboard>

Dengan atribut apps-script-url, semua hasil otomatis tersimpan ke Google Sheets.

📊 Integrasi Google Sheets — Satu Sheet untuk Semua Hari

Semua halaman pertemuan bisa menggunakan satu Google Sheet yang sama. Setup:

  1. Buat satu Google Sheet untuk seluruh course
  2. Deploy Apps Script dari Code.gs satu kali
  3. Gunakan URL yang sama di semua halaman pertemuan

Dengan <full-quiz-dashboard>:

<full-quiz-dashboard apps-script-url="https://script.google.com/macros/s/SAME_ID/exec"></full-quiz-dashboard>

Sheet akan otomatis punya data dari semua pertemuan. Kolom "Tipe Aktivitas" membedakan sumber data (reading, quiz, discussion, dll).

📝 Mengedit Soal Kuis di HAXcms

Saat dosen membuka halaman di HAXcms editor:

  1. Komponen kuis akan menampilkan tombol "Edit Soal Kuis"
  2. Klik untuk membuka panel editor soal
  3. Tambah/edit/hapus soal sesuai kebutuhan
  4. Klik Simpan & Keluar
📝 Catatan: Soal kuis tersimpan di localStorage browser. Untuk deployment ke production, soal sebaiknya di-hardcode di atribut questions atau dikelola via Google Sheets.
