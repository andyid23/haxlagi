🛠️ Cara Menambahkan Elemen ke Halaman

Metode 1: Editor Visual HAXcms

  1. Klik tombol Tambah Elemen (+) di panel kiri editor.
  2. Cari nama elemen di bilah pencarian (misal: "Explode Quiz").
  3. Klik atau seret elemen ke halaman untuk menyisipkannya.

Metode 2: Mode Source (HTML)

  1. Klik mode Source di editor HAXcms.
  2. Tempel tag elemen langsung, contoh: <explode-quiz></explode-quiz>
  3. Simpan perubahan.

📦 Atribut & Konfigurasi Umum

Semua elemen mendukung atribut HTML standar untuk konfigurasi:

  • spreadsheet-id — ID Google Spreadsheet untuk sinkronisasi data
  • editable — Mengaktifkan mode edit (true/false)
  • type — Tipe notifikasi: info, success, warning, error
  • message — Pesan yang ditampilkan
  • duration — Durasi tampil dalam milidetik

🔧 Integrasi Google Sheets

Elemen kuis (explode-quiz, quiz-dashboard-lite) mendukung integrasi Google Sheets untuk menyimpan hasil kuis secara real-time:

  1. Masukkan ID atau URL Google Spreadsheet melalui atribut spreadsheet-id.
  2. Atau gunakan UI dashboard untuk menghubungkan/membuat spreadsheet baru.
  3. Hasil kuis otomatis tersimpan ke sheet dengan format: Timestamp, Nama, Skor.
