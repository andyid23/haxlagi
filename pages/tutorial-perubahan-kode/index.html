📘 Tutorial Perubahan Kode v2: Single Login, KD-Materi & Split Assignment/Forum

Panduan migrasi dari arsitektur lama ke arsitektur baru v2. Semua perubahan backward compatible — halaman lama tetap berfungsi.

🎯 Ringkasan Perubahan Utama

  • Single Login: Login sekali, akses semua halaman (auto-login via quiz-user-auth auto-login)
  • KD-Materi dari sheet-name: kdMateri = sheetName otomatis, filter aktivitas per pertemuan
  • Split Assignment/Forum: assignment-component + forum-component (lama: assignment-forum dengan hide-tugas)
  • Session 24h + Auto-logout: expiresAt di localStorage, auto-logout 24 jam
  • Generate Soal Fix: question-generator sekarang nemu explode-quiz di shadow DOM

🔐 1. Single Login & Auto-Login

Perubahan di quiz-user-auth.js

// Baru: property autoLogin (default true)
autoLogin: { type: Boolean, attribute: "auto-login" }

// Baru: session dengan expiresAt 24h
_save(key, val) {
  const data = { ...val, expiresAt: Date.now() + 24 * 60 * 60 * 1000 };
  localStorage.setItem(key, JSON.stringify(data));
}

// Baru: event session-changed untuk sync semua elemen
_dispatchSessionChanged() {
  const session = this._load("quiz_user_session");
  window.dispatchEvent(new CustomEvent("quiz-user-session-changed", {
    detail: session, bubbles: true, composed: true
  }));
}

Cara Pakai di Halaman

Behavior:

  • Halaman pertama: user login → session tersimpan 24h
  • Halaman berikutnya: auto-login cek session → valid → auto logged-in
  • Session expired (24h) → auto clear → tampil form login
  • Logout di satu halaman → quiz-user-session-changed event → semua halaman auto-logout

🏷️ 2. KD-Materi dari sheet-name

Semua elemen sekarang punya getter kdMateri yang otomatis ambil dari sheetName:

get kdMateri() {
  return this.sheetName || "Pertemuan"
}

Elemen yang sudah update:

  • activity-logger → kirim kdMateri ke logActivity
  • attendance-tracker & engagement-score → filter by kdMateri
  • explode-quiz → simpan kdMateri di log kuis
  • question-generator → baca kdMateri dari quiz target
  • assignment-component & forum-component → kirim kdMateri ke Apps Script

🛠️ 4. Deploy Ulang Apps Script (Wajib!)

Karena ada kolom baru kdMateri di sheet, wajib re-deploy kedua Apps Script:

A. Main Apps Script (code.gs)

  1. Buka spreadsheet → Extensions → Apps Script
  2. Copy-paste code.gs terbaru (sudah ada kolom kdMateri di logActivity, getActivityHistory filter by kdMateri)
  3. Save → Deploy → Manage deployments → Edit → New version → Deploy
  4. Copy URL baru → update apps-script-url di halaman

B. Forum & Tugas (code-forum-tugas.gs)

  1. Buka spreadsheet yang sama → Extensions → Apps Script (project terpisah)
  2. Copy-paste code-forum-tugas.gs terbaru (kolom kdMateri di Forum Log & Tugas Log, filter by kdMateri)
  3. Save → Deploy → Manage deployments → Edit → New version → Deploy
  4. Copy URL baru → update forum-api-url di halaman
⚠️ Penting: Setelah re-deploy, clear cache browser (Ctrl+Shift+R) agar load bundle JS terbaru.
