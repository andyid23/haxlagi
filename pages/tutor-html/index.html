📖 Belajar Dasar HTML untuk Pemula 🇮🇩

Tutorial lengkap HTML dari nol — tanpa perlu install apa pun. Cukup browser dan teks editor (Notepad pun bisa!). HTML adalah bahasa markup untuk membuat struktur halaman web. Ibarat rumah: HTML adalah kerangka bangunannya.

🔤 Bab 1: Tag HTML Dasar

HTML ditulis dengan tag — diapit tanda kurung siku < >. Setiap tag punya fungsi spesifik.

Tag Paling Sering Dipakai

TagFungsiContoh
<h1> - <h6>Heading / judul (1 = terbesar)<h1>Judul</h1>
<p>Paragraf teks<p>Ini paragraf</p>
<a>Link / tautan<a href="url">Klik</a>
<img>Gambar<img src="foto.jpg">
<ul> / <ol>Daftar (list)<ul><li>Item</li></ul>
<table>Tabel data<table><tr><td>Sel</td></tr></table>
<div>Kontainer / pembagian area<div>...</div>
<span>Teks dalam satu baris<span>teks</span>
<br>Baris baru (line break)Baris 1<br>Baris 2
<hr>Garis horizontal pemisah<hr>

Struktur Dasar Halaman HTML

<!DOCTYPE html>
<html>
<head>
  <title>Judul Halaman</title>
</head>
<body>
  <h1>Halo Dunia!</h1>
  <p>Ini halaman web pertama saya.</p>
</body>
</html>
💡 Ingat: Sebagian besar tag HTML punya tag pembuka <p> dan tag penutup </p>. Beberapa tag seperti <br> dan <img> tidak butuh penutup (self-closing).

🎨 Bab 2: Atribut HTML

Atribut adalah informasi tambahan di dalam tag. Ditulis dengan format nama="nilai".

Atribut Wajib Tahu

AtributDigunakan diFungsi
href<a>URL tujuan link
src<img>Path file gambar
alt<img>Teks alternatif jika gambar gagal
classsemuaNama kelas untuk CSS styling
idsemuaID unik untuk elemen
stylesemuaCSS inline langsung
target<a>_blank = buka di tab baru

Contoh Penggunaan:

<!-- Link ke Google, buka di tab baru -->
<a href="https://google.com" target="_blank">Ke Google</a>

<!-- Gambar dengan teks alternatif -->
<img src="foto.jpg" alt="Foto pemandangan">

<!-- Paragraf dengan class untuk CSS -->
<p class="highlight">Teks yang diberi gaya khusus</p>

📋 Bab 3: Membuat Daftar (List)

Ada dua jenis daftar di HTML:

Unordered List (ul)

Daftar tanpa nomor, pakai bullet:

<ul>
  <li>Apel</li>
  <li>Jeruk</li>
  <li>Mangga</li>
</ul>

Hasil:

  • Apel
  • Jeruk
  • Mangga

Ordered List (ol)

Daftar bernomor:

<ol>
  <li>Langkah 1</li>
  <li>Langkah 2</li>
  <li>Langkah 3</li>
</ol>

Hasil:

  1. Langkah 1
  2. Langkah 2
  3. Langkah 3

📊 Bab 4: Membuat Tabel

Tabel digunakan untuk menampilkan data terstruktur:

<table>
  <thead>
    <tr>
      <th>Nama</th>
      <th>Nilai</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>Andi</td>
      <td>85</td>
    </tr>
    <tr>
      <td>Budi</td>
      <td>90</td>
    </tr>
  </tbody>
</table>
📝 Penjelasan:
<thead> = header tabel (judul kolom)
<tbody> = body tabel (isi data)
<tr> = table row (baris)
<th> = table header cell (sel judul, tebal)
<td> = table data cell (sel data biasa)

🎯 Bab 5: Membuat Formulir (Form)

Form digunakan untuk mengumpulkan input dari pengguna:

<form>
  <label>Nama:</label>
  <input type="text" placeholder="Masukkan nama">

  <label>Email:</label>
  <input type="email" placeholder="email@contoh.com">

  <label>Password:</label>
  <input type="password">

  <label>Jenis Kelamin:</label>
  <input type="radio" name="jk"> Laki-laki
  <input type="radio" name="jk"> Perempuan

  <label>Hobi:</label>
  <input type="checkbox"> Membaca
  <input type="checkbox"> Olahraga

  <label>Pesan:</label>
  <textarea rows="4"></textarea>

  <button type="submit">Kirim</button>
</form>

Tipe Input Penting:

TipeFungsi
textTeks satu baris
emailInput email (validasi otomatis)
passwordInput tersembunyi (••••)
numberInput angka saja
radioPilih satu dari beberapa opsi
checkboxCentang banyak opsi
datePemilih tanggal
fileUpload file
buttonTombol
submitTombol kirim form

🖼️ Bab 6: Gambar, Link, dan Multimedia

Gambar

<img src="url-gambar.jpg" alt="Deskripsi" width="300" height="200">

Link

<!-- Link biasa -->
<a href="https://contoh.com">Klik di sini</a>

<!-- Link buka di tab baru -->
<a href="https://contoh.com" target="_blank">Buka Tab Baru</a>

<!-- Link download file -->
<a href="file.pdf" download>Download PDF</a>

<!-- Link ke anchor di halaman yang sama -->
<a href="#bab3">Lompat ke Bab 3</a>

Video (YouTube)

<video-player source="https://www.youtube.com/watch?v=xxxx"></video-player>

🏗️ Bab 7: Div dan Layout Dasar

<div> adalah elemen kontainer paling penting di HTML. Digunakan untuk mengelompokkan elemen lain.

<div style="background: #f0f0f0; padding: 20px; border-radius: 8px;">
  <h3>Judul Section</h3>
  <p>Konten di dalam div ini...</p>
  <button>Tombol</button>
</div>

Grid Sederhana dengan grid-plate (HAX Component)

<grid-plate layout="1-1">
  <div slot="col-1">Kolom Kiri</div>
  <div slot="col-2">Kolom Kanan</div>
</grid-plate>

🎨 Bab 8: Dasar CSS (Inline Style)

CSS mengatur tampilan visual. Cara termudah: gunakan atribut style langsung di tag.

Properti CSS Penting:

PropertiFungsiContoh Nilai
colorWarna teksred, #333, rgb(0,0,255)
backgroundLatar belakang#f0f0f0, linear-gradient(...)
font-sizeUkuran teks16px, 1.2em, large
font-weightKetebalan teksbold, normal, 600
marginJarak luar10px, 0 auto
paddingJarak dalam16px, 8px 16px
borderGaris tepi1px solid #ccc
border-radiusSudut melengkung8px, 50%
text-alignRata tekscenter, left, right
displayMode tampilanflex, grid, block
width / heightLebar / tinggi100%, 300px, auto

Contoh Gabungan:

<div style="
  background: linear-gradient(135deg, #6750a4, #9c7cf4);
  color: white;
  padding: 24px;
  border-radius: 12px;
  text-align: center;
  font-size: 18px;
  margin: 16px 0;
">
  <h2>Kotak Gradien Ungu</h2>
  <p>Ini contoh styling dengan inline CSS</p>
</div>
