📊 Dashboard Siswa — Lihat Nilai & Aktivitas dari Google Sheets

Halaman ini mengambil data langsung dari Google Sheets via Apps Script API. Masukkan URL Apps Script dan nama Anda, lalu klik Tampilkan untuk melihat semua data kuis, aktivitas, dan leaderboard Anda secara real-time.

🔌 Hubungkan ke Google Sheets

Masukkan URL Apps Script Web App dan nama Anda untuk melihat data.

Mengambil data dari Google Sheets...

📊 Cara Kerja

  1. Masukkan URL Apps Script — sama dengan yang dipakai di dashboard kuis
  2. Masukkan nama Anda — data dicocokkan dengan nama di sheet
  3. Klik Tampilkan — fetch data dari Apps Script API GET endpoint
  4. Jelajahi tab: Leaderboard, Kuis Saya, Aktivitas Saya, Pertemuan

Endpoint API yang Digunakan:

ActionURLReturn
leaderboard?action=leaderboardSemua siswa dari sheet Rangkuman
summary?action=summary&name=AndiData satu siswa
pertemuan?action=pertemuan&sheet=Pertemuan 1Semua siswa di pertemuan
aktivitas?action=aktivitas&sheet=Pertemuan 1&name=AndiLog aktivitas siswa
list?action=listDaftar sheet tab
