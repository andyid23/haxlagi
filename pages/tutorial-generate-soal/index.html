📘 Tutorial Generate Soal dari Bank Soal (Fix "Elemen kuis tidak ditemukan")

Panduan lengkap setup Bank Soal, deploy getBankSoal, konfigurasi question-generator, dan troubleshooting error "Elemen kuis tidak ditemukan".

🎯 Alur Kerja Generate Soal

  1. Dosen buka halaman dengan lecturer-console (mode dosen)
  2. Klik 🗂️ Generate Soal dari Bank Soal
  3. question-generator POST getBankSoal ke Apps Script
  4. Apps Script baca sheet Bank Soal → return soal JSON
  5. question-generator map soal → kirim ke explode-quiz via loadQuestions()
  6. Soal muncul di tab 📝 Ambil Kuis → siswa bisa kerjakan

🚀 2. Deploy getBankSoal ke Apps Script

Prasyarat: code.gs sudah punya action getBankSoal (sudah ada di repo).

  1. Buka spreadsheet → Extensions → Apps Script (project utama code.gs)
  2. Pastikan kode getBankSoal ada di dalam doGet & doPost switch:
case "getBankSoal": return response(getBankSoal(e.parameter));
  1. Save (Ctrl+S)
  2. Deploy → Manage deployments → Edit (ikon pensil) → New version → Deploy
  3. Copy URL Web App baru
✅ Verifikasi Deploy: Buka URL https://script.google.com/macros/s/URL/exec?action=getBankSoal&kategori=campur di browser → harus return JSON {"status":"ok","total":8,"questions":[...]}

🔧 4. Fix "Elemen kuis tidak ditemukan"

Penyebab

question-generator._getQuizElement() cari quiz-selector (default #quiz) tapi explode-quiz berada di dalam shadow DOM quiz-dashboard-lite2 → querySelector tidak nemu.

Fix yang Sudah Diimplementasi

Di question-generator.js, method _getQuizElement() sekarang:

  1. Traverse shadow DOM host chain (existing logic)
  2. Fallback: cari di document (light DOM)
  3. Fallback: cari explode-quiz pertama di document
_getQuizElement() {
  // 1. Traverse shadow DOM ancestors
  let scope = this.getRootNode();
  while (scope) {
    const found = scope.querySelector ? scope.querySelector(this.quizSelector) : null;
    if (found) return found;
    scope = scope.host ? scope.host.getRootNode() : null;
  }
  // 2. Fallback: document (light DOM)
  const docQuiz = document.querySelector(this.quizSelector);
  if (docQuiz) return docQuiz;
  // 3. Fallback: explode-quiz pertama
  const allQuizzes = document.querySelectorAll('explode-quiz');
  if (allQuizzes.length > 0) return allQuizzes[0];
  return null;
}

Pastikan di Halaman:

  • explode-quiz punya id="quiz" (default di quiz-dashboard-lite2)
  • question-generator pakai quiz-selector="#quiz" (default)
  • Bundle JS sudah di-rebuild (npm run build di folder custom)
