💡 Rekomendasi: Aktivitas Pembelajaran dengan Quiz Dashboard

Panduan best practices untuk memaksimalkan penggunaan <full-quiz-dashboard> dan <student-dashboard> dalam kegiatan belajar mengajar.

🎯 Prinsip Utama

  • Konsisten: Setiap pertemuan punya kuis + aktivitas yang tercatat
  • Otomatis: Pelacakan aktivitas jalan di background tanpa perlu input manual
  • Transparan: Siswa lihat skor & ranking mereka secara real-time

📅 Strategi per Pertemuan

Sebelum Kelas Dimulai

  • Siapkan kd-materi unik untuk pertemuan (contoh: UH-1, UH-2)
  • Buat sheet-name sesuai jadwal (contoh: Pertemuan 1)
  • Pastikan Apps Script sudah deploy & URL aktif

Saat Kelas Berlangsung

  1. Buka materi → <full-quiz-dashboard> otomatis mencatat aktivitas membaca
  2. Forum diskusi → siswa bertanya & menjawab → aktivitas forum tercatat
  3. Kuis singkat → 5 soal → skor langsung masuk Google Sheets
  4. Tugas mandiri → siswa kirim tugas + link Google Drive

Setelah Kelas

  • Cek <student-dashboard> → lihat leaderboard & heatmap siswa
  • Export data dari Google Sheets untuk rapor
  • Identifikasi siswa yang perlu bimbingan (skor rendah / aktivitas minim)

🏆 Pemanfaatan Leaderboard

✅ Tips Motivasi:
  • Tampilkan leaderboard di awal kelas → memotivasi siswa untuk aktif
  • Ranking berdasarkan rata-rata skor + total aktivitas → bukan hanya skor kuis
  • Beri penghargaan untuk top 3 di akhir bulan

Fitur heatmap menampilkan aktivitas siswa selama 6 minggu terakhir (seperti GitHub contribution graph).

📊 Monitoring untuk Pengajar

Yang Perlu Dipantau

  • Skor kuis per pertemuan → identifikasi materi yang sulit
  • Total aktivitas → siswa aktif vs pasif
  • Forum diskusi → tingkat partisipasi & kualitas diskusi
  • Tugas → ketepatan waktu & kualitas jawaban

Red Flag (Perlu Perhatian Khusus)

  • ❌ Skor kuis < 40 secara konsisten
  • ❌ Tidak ada aktivitas selama 1 minggu
  • ❌ Tidak pernah posting di forum
  • ❌ Tugas selalu terlambat

📈 Best Practices Google Sheets

  • Jangan edit sheet manual → biarkan Apps Script yang mengelola
  • Backup berkala → File → Download → .xlsx
  • Gunakan filter → Data → Create filter untuk analisis cepat
  • Conditional formatting → warnai kolom Skor: hijau untuk ≥70, merah untuk <70
