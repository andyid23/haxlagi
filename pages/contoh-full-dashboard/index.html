📘 Contoh: Full Quiz Dashboard + Student Dashboard

Halaman demo menunjukkan cara <full-quiz-dashboard> dan <student-dashboard> bekerja bersama. kd-materi dan sheet-name di-sync otomatis ke semua komponen.

⚡ Cara Kerja Sync

  1. Set kd-materi="UH-1" dan sheet-name="Pertemuan 1" di parent component
  2. Nilai otomatis diwariskan ke <full-quiz-dashboard>, <attendance-logger>, <activity-logger>
  3. Semua komponen menulis ke sheet yang sama: Pertemuan 1 - Kuis / Pertemuan 1 - Aktivitas
  4. <student-dashboard> membaca dari sheet yang sama untuk leaderboard & summary

🔐 Login

👩‍🎓 Mode Siswa — Full Quiz Dashboard

Kuis interaktif + pelacakan aktivitas otomatis + heatmap kehadiran. Data dikirim ke Google Sheets.

👨‍🏫 Mode Dosen — Full Quiz Dashboard

Dashboard lengkap dosen: lihat semua jawaban siswa, edit soal, generate soal dari bank soal.

📊 Student Dashboard — Leaderboard & Statistik

Menampilkan leaderboard, ringkasan skor, dan heatmap aktivitas dari Google Sheets.

⚙️ Atribut yang tersedia

AtributKomponenKeterangan
kd-materiSemua komponenKode materi unik (contoh: UH-1). Sync otomatis.
sheet-namequiz-dashboard, full-quiz-dashboardNama pertemuan (contoh: Pertemuan 1). Menentukan suffix sheet.
apps-script-urlSemua komponenURL Apps Script Web App yang sama.

📋 Catatan Penting

  • Satukan kd-materi: Semua komponen dalam satu pertemuan harus pakai kd-materi yang sama.
  • Sheet otomatis: Apps Script membuat sheet {Pertemuan} - Kuis dan {Pertemuan} - Aktivitas otomatis.
  • Leaderboard: <student-dashboard> menggabungkan data dari semua sheet pertemuan.
