📖 Tutorial: Langkah-Langkah Setup Full Quiz Dashboard

Panduan lengkap setup <full-quiz-dashboard> + <student-dashboard> dari nol sampai berjalan.

Langkah 1: Siapkan Google Spreadsheet

  1. Buka Google Sheets → buat spreadsheet baru
  2. Beri nama: Data Kuis Kelas XI (atau sesuai kebutuhan)
  3. Copy Spreadsheet ID dari URL: https://docs.google.com/spreadsheets/d/{SPREADSHEET_ID}/edit

Langkah 2: Setup Apps Script

  1. Di spreadsheet → Extensions → Apps Script
  2. Hapus isi Code.gs yang ada, lalu tempel kode dari files/apps-script-backend.gs
  3. Klik Deploy → New deployment
  4. Pilih type: Web app
  5. Execute as: Me
  6. Who has access: Anyone
  7. Klik Deploy → salin URL /exec
✅ Tips: Setelah deploy pertama, setiap kali mengubah kode di Apps Script, klik Deploy → Edit deployments → klik ikon ✏️ → pilih New version → Deploy.

Langkah 3: Buat Struktur Sheet (Opsional)

  1. Di Apps Script, jalankan fungsi setupStruktur() via menu 🎓 Kuis Toolkit → 1. Buat struktur sheet
  2. Atau jalankan manual: Apps Script editor → pilih setupStruktur → klik ▶️ Run
  3. Ini akan membuat 6 sheet: Pertemuan 1 - Kuis, Pertemuan 1 - Aktivitas, dst.

Langkah 4: Pasang di Halaman HAXcms

Buka halaman yang ingin diedit, lalu tambahkan komponen berikut:

4a. Login (wajib)

<quiz-user-auth
  apps-script-url="https://script.google.com/macros/s/YOUR_ID/exec"
  auto-login>
</quiz-user-auth>

4b. Full Quiz Dashboard (Mode Siswa)

<full-quiz-dashboard
  apps-script-url="https://script.google.com/macros/s/YOUR_ID/exec"
  sheet-name="Pertemuan 1"
  kd-materi="UH-1">
</full-quiz-dashboard>

4c. Student Dashboard (Leaderboard)

<student-dashboard
  apps-script-url="https://script.google.com/macros/s/YOUR_ID/exec"
  student-name=""
  _active-tab="leaderboard">
</student-dashboard>

Langkah 5: Set KD Materi

⚠️ Penting: Pastikan semua komponen dalam satu pertemuan pakai kd-materi yang SAMA.

Cara set di HAX UI:

  1. Klik komponen → klik ikon ⚙️ (settings)
  2. Isi Kode Materi (KD): UH-1 (atau kode unik lain)
  3. Isi Nama Sheet/Pertemuan: Pertemuan 1
  4. Simpan

Cara set via HTML attribute:

<full-quiz-dashboard
  kd-materi="UH-1"
  sheet-name="Pertemuan 1">
</full-quiz-dashboard>

Langkah 6: Testing

  1. Buka halaman yang sudah dipasang komponen
  2. Login sebagai siswa (NIS dan nama)
  3. Kerjakan kuis → skor akan terkirim ke sheet
  4. Buka Google Spreadsheet → cek sheet Pertemuan 1 - Kuis
  5. Buka <student-dashboard> → cek leaderboard

Langkah 7: Troubleshooting

MasalahSolusi
Data tidak masuk sheetCek URL Apps Script benar. Buka URL langsung di browser → harus return JSON.
Leaderboard kosongPastikan <student-dashboard> pakai URL yang sama dengan <full-quiz-dashboard>.
kd-materi tidak syncPastikan semua komponen punya kd-materi yang sama. Cek di HAX UI settings.
Sheet belum adaJalankan setupStruktur() di Apps Script, atau submit kuis pertama kali (sheet dibuat otomatis).
