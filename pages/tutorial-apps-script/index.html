📖 Tutorial: Setup Google Apps Script

Panduan langkah demi langkah untuk menghubungkan kuis dengan Google Sheets tanpa server backend. Menggunakan Google Apps Script sebagai jembatan.

🎯 Alur Sistem

Siswa mengerjakan kuis di browser → Browser kirim data via POST → Apps Script terima & proses → Tersimpan di Google Sheets.

✅ Kelebihan

  • Tidak perlu server, Firebase, atau backend
  • Gratis — Google Apps Script gratis untuk 20,000 eksekusi/hari
  • Data langsung tersimpan di Google Drive Anda

⚠️ Keterbatasan

  • Hanya bisa menyimpan data (POST), tidak membaca
  • Untuk leaderboard perlu Firebase atau backend server

📋 Persiapan

  • Akun Google (Gmail)
  • Browser web modern
  • File Code.gs (tersedia di custom/src/Code.gs)

🚀 Langkah 1: Buat Google Spreadsheet

  1. Buka Google Sheets
  2. Klik "Blank" untuk spreadsheet baru
  3. Beri nama: "Hasil Kuis Interaktif"
  4. Copy ID dari URL spreadsheet Anda
URL format: https://docs.google.com/spreadsheets/d/[ID_DISINI]/edit

🚀 Langkah 2: Buka Apps Script

  1. Di Google Sheets, klik menu Extensions → Apps Script
  2. Akan terbuka tab editor baru
  3. Hapus semua kode default yang ada

🚀 Langkah 3: Copy-Paste Code.gs

Copy seluruh kode dari file Code.gs dan paste ke editor Apps Script.

Kode mencakup handler:

  • doGet() — Health check
  • doPost() — Terima data kuis + attendance
  • saveQuiz() — Simpan hasil kuis ke sheet
  • saveAttendance() — Simpan log aktivitas ke sheet
  • updateSummary() — Agregasi per siswa

🚀 Langkah 4: Deploy

  1. Klik Deploy → New deployment
  2. Pilih type: Web app
  3. Execute as: Me
  4. Who has access: Anyone
  5. Klik Deploy, lalu Authorize access
  6. Copy URL Web App yang dihasilkan

🚀 Langkah 5: Hubungkan ke Dashboard

  1. Paste URL di form Setup tab dashboard
  2. Atau gunakan atribut: <full-quiz-dashboard apps-script-url="URL">
  3. Selesai! Setiap kuis selesai, data otomatis ke Sheets

🔧 Troubleshooting

Error: "Gagal menyimpan ke Sheets"

  • Pastikan URL diawali https://script.google.com/macros/s/
  • Pastikan deployment type "Web app", bukan "API Executable"
  • Pastikan "Who has access" = "Anyone"

Error otorisasi saat deploy

  • Klik "Advanced" di dialog peringatan
  • Klik "Go to [project name] (unsafe)"
  • Klik "Allow"
  • Aman karena script milik Anda sendiri

Data tidak muncul di Sheets

  • Buka Apps Script editor → Executions di sidebar kiri
  • Cek error log
  • Pastikan kode di-copy lengkap
