🔧 Cara Pakai Generate Soal dari Bank Soal

📋 Langkah Generate Soal (Mode Dosen)

  1. Pastikan sudah login sebagai dosen (akses halaman ini)
  2. Buka tab 🛠️ Console Dosen di dashboard di atas
  3. Klik tombol 🗂️ Generate Soal dari Bank Soal
  4. Tunggu notifikasi: Soal dari Bank Soal dimuat: X soal (campur).
  5. Otomatis pindah ke tab 📝 Ambil Kuis
  6. Soal siap dikerjakan oleh siswa

Catatan: Butuh sheet Bank Soal di spreadsheet dengan kolom: ID | Kategori | Tipe | Soal | Detail | Gambar | Poin

📊 Generate Laporan Rapor (Dosen)

📋 Langkah Generate Rapor

  1. Buka tab 🛠️ Console Dosen
  2. Atur bobot 6 komponen (Kehadiran, UH, UTS, UAS, Sikap, Keterampilan)
  3. Input nilai manual UTS/UAS per siswa di kolom tabel
  4. Klik 📊 Generate Laporan Rapor
  5. Hasil: Sheet Akumulasi Nilai Rapor terisi (Nilai Akhir + Grade)
  6. Siswa lihat nilai di tab 📊 Daftar Skor (mode siswa)

Rumus: (Kehadiran×bKeh + UH×bUH + UTS×bUTS + UAS×bUAS + Sikap×bSikap + Keterampilan×bKer) / total bobot

Sikap & Keterampilan Auto-calc: Sikap = tugas×25 + forum×20 (max 100), Keterampilan = kuis×30 + baca×10 (max 100)

🏷️ KD-Materi = UH1 (Dari sheet-name)

Semua elemen di atas pakai kd-materi="UH-1" → otomatis kdMateri="UH1":

  • Forum Log → filter kdMateri=UH1
  • Tugas Log → filter kdMateri=UH1
  • Aktivitas Log → filter kdMateri=UH1
  • Attendance Tracker → hitung hanya aktivitas UH1
  • Heatmap → hanya aktivitas UH1
  • Kuis → simpan kdMateri=UH1
  • Bank Soal → filter kategori by kdMateri
