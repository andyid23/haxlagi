📊 Tutorial: 1 Google Sheet = 1 Course — 1 Sheet Tab = 1 Pertemuan

Cara setup agar satu Google Spreadsheet menampung seluruh data course, dan setiap sheet tab otomatis jadi satu pertemuan. Data dari semua halaman HAXcms masuk ke spreadsheet yang sama, terorganisir rapi per pertemuan.

🎯 Konsep

1 Spreadsheet 1 Sheet Tab 1 Atribut HTML
= 1 Course/Mata Kuliah = 1 Pertemuan/Hari sheet-name="Pertemuan 1"

🚀 Langkah 1: Buat 1 Google Spreadsheet untuk 1 Course

  1. Buka sheets.google.com
  2. Klik "Blank" — buat spreadsheet baru
  3. Beri nama: "Course: HAXcms & Web Component" (atau nama course Anda)
  4. Jangan buat sheet tab dulu — Apps Script akan auto-create!

🚀 Langkah 2: Copy-Paste Code.gs ke Apps Script

  1. Di spreadsheet, klik Extensions → Apps Script
  2. Hapus kode default yang ada
  3. Copy-paste seluruh kode dari Code.gs (tersedia di custom/src/Code.gs)
  4. Klik Save (ikon disket) — beri nama project: "QuizHandler"
📝 Apa yang dilakukan Code.gs v2?
• doPost() — Menerima data kuis (nama, skor, sheet) via POST JSON
• saveToSheet() — Auto-create sheet tab jika belum ada, lalu append data
• updateSummary() — Baca seluruh sheet tab dan buat agregasi di sheet "Rangkuman"
• Setiap sheet tab punya header: Timestamp | Nama | Skor | Total Soal | Status

🚀 Langkah 3: Deploy sebagai Web App

  1. Klik Deploy → New deployment
  2. Klik ikon gear ⚙️ — pilih Web app
  3. Isi konfigurasi:
    • Description: "Quiz API"
    • Execute as: Me
    • Who has access: Anyone
  4. Klik Deploy
  5. Klik Authorize access — pilih akun Google Anda
  6. Jika muncul peringatan "Google hasn't verified this app":
    • Klik Advanced
    • Klik Go to QuizHandler (unsafe)
    • Klik Allow
  7. COPY URL Web App! Format: https://script.google.com/macros/s/AKfycbx.../exec
⚠️ Penting: URL ini akan dipakai di SEMUA halaman pertemuan. Simpan baik-baik!

🚀 Langkah 4: Setup di Halaman HAXcms

Di setiap halaman pertemuan, tambahkan dashboard dengan atribut sheet-name yang berbeda:

🔧 Troubleshooting

❌ Data tidak muncul di sheet

  • Cek Console browser (F12) — lihat apakah ada error CORS
  • Apps Script harus di-deploy sebagai Web app, bukan API Executable
  • "Who has access" harus Anyone
  • Setelah deploy ulang (edit kode), Anda dapat URL BARU — update di semua halaman!

❌ Sheet tab tidak auto-create

  • Pastikan atribut sheet-name tertulis benar (case-sensitive)
  • Cek di Apps Script editor → Executions → lihat error log
  • Jalankan fungsi test() manual dari editor untuk debug

❌ Error: "Google hasn't verified this app"

  • Ini normal untuk script pribadi
  • Klik Advanced → Go to QuizHandler (unsafe) → Allow
  • Hanya muncul saat pertama kali authorize

❌ Ingin update kode Apps Script?

  • Edit kode di editor Apps Script
  • Klik Deploy → New deployment — ini akan generate URL BARU
  • Update URL di semua halaman HAXcms
  • Alternatif: Deploy → Manage deployments → Edit (icon pensil) → Version: New → Deploy
