🎯 Full Quiz Dashboard — Satu Elemen, Semua Fitur

Elemen <full-quiz-dashboard> adalah Web Component vanilla JavaScript (0 dependencies) yang menggabungkan semua fitur dalam satu tag: Kuis + Attendance + Heatmap + Gradebook + Google Sheets.

🛠️ Fitur Lengkap

  • 0 Dependencies: Pure vanilla JS, tidak butuh Lit, Firebase, atau library apapun
  • Google Sheets via Apps Script: Hasil kuis + log attendance otomatis tersimpan
  • Activity Logger: Deteksi scroll, klik, unduhan otomatis
  • Attendance Gauge: Kalkulasi kehadiran real-time
  • Heatmap 28 Hari: Visualisasi konsistensi belajar
  • Gradebook Transparan: Bobot nilai bisa dikustomisasi
  • Mode Dosen: Ubah threshold, bobot, input UTS/UAS
  • Simulator: Tombol simulasi aktivitas untuk testing

📦 Google Apps Script (Code.gs)

Script tersedia di direktori custom/src/Code.gs. Setup:

  1. Buka Google Sheets → Extensions → Apps Script
  2. Copy-paste isi Code.gs
  3. Deploy → New deployment → Web app
  4. Execute as: Me, Who has access: Anyone
  5. Copy URL dan gunakan di atribut apps-script-url
