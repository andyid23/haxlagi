📊 Tutorial: Sistem Attendance & Activity Logging

Panduan lengkap cara kerja pelacakan aktivitas dan kehadiran otomatis. Kehadiran dihitung berdasarkan aktivitas pembelajaran, bukan tanda tangan manual.

🎯 Konsep Utama

Kehadiran = Aktivitas Belajar yang Terdeteksi Otomatis oleh Sistem

⚙️ Cara Kerja Sistem

1. Event Listeners (Deteksi Otomatis)

EventTriggerTipe AktivitasThrottle
scrollUser scroll > 300pxreading1x per 60 detik
clickKlik link/buttonreading/downloadSetiap klik valid
quiz-savedKuis selesaiquizSetiap kuis selesai

2. Penyimpanan Data

Semua aktivitas tersimpan di localStorage browser dengan key a3_attendance_activity_logs.

3. Perhitungan Kehadiran (7 Hari Terakhir)

KriteriaMinimalCara Terpenuhi
📖 Membaca Modul2xScroll materi atau klik link
📝 Kuis Selesai1xMengerjakan kuis apapun
💬 Forum & Diskusi1xKlik tombol diskusi/forum
📈 Total Aktivitas5xSemua jenis aktivitas digabung

Rumus: Kehadiran = (Jumlah Kriteria Terpenuhi / 4) × 100%
≥ 75% = HADIR

🧩 Komponen Web

📊 <activity-logger>

  • Deteksi scroll (throttle 60 detik)
  • Deteksi klik link download
  • Deteksi kuis selesai (event quiz-saved)
  • Toast notification
  • Floating pill dengan counter aktivitas
  • Simulator untuk testing

Tag: <activity-logger></activity-logger>

📅 <attendance-tracker>

  • Gauge chart persentase kehadiran
  • Checklist 4 kriteria kehadiran
  • Progress bar per kriteria
  • Auto-update via event a3-activity-logged

🔥 <engagement-score>

  • Heatmap grid 28 hari (seperti GitHub)
  • 5 level warna berdasarkan jumlah aktivitas
  • Klik cell untuk lihat detail per hari
  • Streak counter (hari berturut-turut aktif)
  • Consistency index (persentase hari aktif)

📖 <transparent-gradebook>

  • Summary bento grid nilai
  • Tabel rinci setiap komponen
  • Mode Dosen (input UTS/UAS, ubah bobot)
  • Roster simulasi anggota kelas
  • Bobot default: Kehadiran 30%, Kuis 20%, UTS 25%, UAS 25%

🔧 Customisasi

Ubah Threshold Kehadiran

// Console browser (F12)
localStorage.setItem('a3_attendance_threshold_config', JSON.stringify({
  minWeeklyActivities: 3,
  minReading: 1,
  minQuiz: 1,
  minDiscussion: 1
}));

Reset Semua Data

localStorage.removeItem('a3_attendance_activity_logs');
localStorage.removeItem('a3_attendance_threshold_config');
localStorage.removeItem('a3_attendance_grades_config');
location.reload();

❓ FAQ

Apakah data attendance otomatis ke Google Sheets?

Tidak. Saat ini data hanya di localStorage. Gunakan <full-quiz-dashboard> dengan Apps Script untuk menyimpan ke Sheets juga.

Apakah data hilang jika ganti browser?

Ya. localStorage bersifat per-browser. Export data secara berkala.

Apakah scroll dihitung terus-menerus?

Tidak. Ada throttle 60 detik — hanya 1 log per menit.
