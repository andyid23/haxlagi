📖 Tutorial: Cara Fetch (Baca) Data dari Google Sheets via Apps Script

Panduan ini menjelaskan cara membaca/mengambil data dari Google Sheets menggunakan Apps Script API, bukan hanya menyimpan. Cocok untuk membuat dashboard siswa, leaderboard, atau halaman monitoring nilai.

🎯 Perbedaan POST vs GET

📤 POST (Simpan Data)

doPost(e) — Digunakan dashboard kuis untuk menyimpan hasil ke sheet.

fetch(URL, {
  method: 'POST',
  body: JSON.stringify({
    name: "Andi",
    score: 80,
    sheet: "Pertemuan 1"
  })
})

📥 GET (Baca Data)

doGet(e) — Digunakan dashboard siswa untuk membaca data dari sheet.

fetch(URL + '?action=summary&name=Andi')
  .then(r => r.json())
  .then(data => {
    // data berisi nilai Andi
    console.log(data);
  })

📡 Endpoint API GET (Code.gs v3)

Apps Script doGet(e) menerima parameter ?action= untuk menentukan data apa yang diminta:

1. Leaderboard — Semua Siswa

GET https://script.google.com/macros/s/.../exec?action=leaderboard

Response JSON:

{
  "status": "ok",
  "leaderboard": [
    {
      "Nama": "Andi",
      "Total Kuis": 3,
      "Rata-rata Skor": 85,
      "Skor Tertinggi": 100,
      "Skor Terendah": 70,
      "Total Aktivitas": 15,
      "Reading": 8,
      "Quiz Activity": 3,
      "Discussion": 2,
      "Download": 2,
      "Jumlah Pertemuan": 3,
      "Status Kuis Terakhir": "LULUS"
    }
  ]
}

2. Summary — Data Satu Siswa

GET https://script.google.com/macros/s/.../exec?action=summary&name=Andi

Response jika ditemukan:

{
  "status": "ok",
  "data": {
    "Nama": "Andi",
    "Total Kuis": 3,
    "Rata-rata Skor": 85,
    ...
  }
}

Response jika belum ada di Rangkuman:

{
  "status": "not_found",
  "message": "Siswa \"Andi\" belum ada di rangkuman.",
  "data": {
    "kuis": [{"pertemuan":"Pertemuan 1","score":80,"status":"LULUS","timestamp":"..."}],
    "aktivitas": [{"pertemuan":"Pertemuan 1","type":"reading","desc":"Membaca modul","timestamp":"..."}],
    "totalKuis": 1,
    "totalAktivitas": 3,
    "rataSkor": 80,
    "skorTertinggi": 80
  }
}

3. Pertemuan — Semua Siswa di Satu Pertemuan

GET https://script.google.com/macros/s/.../exec?action=pertemuan&sheet=Pertemuan 1

Response: Array semua siswa yang sudah mengerjakan kuis di pertemuan tersebut.

4. Aktivitas — Log Aktivitas Siswa

GET https://script.google.com/macros/s/.../exec?action=aktivitas&sheet=Pertemuan 1&name=Andi

Response: Array log aktivitas (reading, quiz, discussion, download) untuk siswa di pertemuan tertentu.

5. List — Daftar Semua Pertemuan

GET https://script.google.com/macros/s/.../exec?action=list

💻 Contoh Kode JavaScript

Fetch data satu siswa + leaderboard

const BASE_URL = 'https://script.google.com/macros/s/YOUR_ID/exec';

async function loadStudentData(nama) {
  try {
    // Ambil leaderboard dan summary sekaligus
    const [lbRes, sumRes] = await Promise.all([
      fetch(BASE_URL + '?action=leaderboard'),
      fetch(BASE_URL + '?action=summary&name=' + encodeURIComponent(nama))
    ]);

    const leaderboard = await lbRes.json();
    const summary = await sumRes.json();

    // Tampilkan di halaman
    console.log('Leaderboard:', leaderboard);
    console.log('Data Saya:', summary);

  } catch (err) {
    console.error('Gagal fetch data:', err);
  }
}

// Panggil dengan nama siswa
loadStudentData('Andi');

Fetch data per pertemuan

async function loadPertemuan(pertemuanName) {
  const [quizRes, actRes] = await Promise.all([
    fetch(BASE_URL + '?action=pertemuan&sheet=' + encodeURIComponent(pertemuanName)),
    fetch(BASE_URL + '?action=aktivitas&sheet=' + encodeURIComponent(pertemuanName))
  ]);

  const quizData = await quizRes.json();
  const actData = await actRes.json();

  console.log('Hasil Kuis:', quizData.siswa);
  console.log('Log Aktivitas:', actData.aktivitas);
}

loadPertemuan('Pertemuan 1');

🔧 Setup di HAXcms

Cara 1: Halaman HTML + JavaScript (Seperti Dashboard Siswa)

Buat halaman baru di HAXcms, isi dengan HTML + JavaScript seperti contoh dashboard siswa. Simpan URL Apps Script di localStorage.

Cara 2: Embed via iframe

<iframe src="dashboard-siswa" width="100%" height="800" style="border: none;"></iframe>

Cara 3: Kirim URL sebagai parameter

<!-- Tambahkan di URL halaman -->
https://sitelo.com/dashboard-siswa?url=SCRIPT_URL&name=Andi

⚠️ Syarat & Ketentuan

SyaratKeterangan
Deploy sebagai Web AppHarus Web app (bukan API Executable), akses "Anyone"
CORSApps Script support CORS untuk GET request. Tidak perlu mode no-cors.
Rate LimitGratis: 20,000 request/hari. Cukup untuk kelas.
Data Real-timeData dibaca langsung dari spreadsheet saat request.
Nama Case-SensitiveNama "Andi" dan "andi" dianggap berbeda. Pastikan konsisten.
Minimal Chrome/FirefoxFetch API dan async/await didukung semua browser modern.
