📖 Tutorial: Dashboard Siswa & Dosen — Optimasi & Setup

Panduan lengkap setup, optimasi, dan penggunaan dashboard siswa dan dashboard dosen di HAXcms dengan integrasi Google Sheets.

🎯 Perbedaan POST vs GET

📤 POST (Simpan Data)

doPost(e) — Digunakan komponen kuis untuk menyimpan hasil ke sheet.

fetch(URL, {
  method: 'POST',
  body: JSON.stringify({
    name: "Andi", score: 80,
    sheet: "Pertemuan 1"
  })
})

📥 GET (Baca Data)

doGet(e) — Digunakan dashboard siswa untuk membaca data dari sheet.

fetch(URL + '?action=summary&name=Andi')
  .then(r => r.json())
  .then(data => console.log(data))

📊 Cara Pakai <student-dashboard>

Gunakan custom element <student-dashboard> untuk menampilkan dashboard siswa secara instan:

<student-dashboard
  apps-script-url="https://script.google.com/macros/s/YOUR_ID/exec"
  student-name="Andi">
</student-dashboard>

Atribut yang Tersedia

AtributTipeWajib?Keterangan

Dashboard otomatis menyimpan URL dan nama di localStorage. Jika sudah pernah diisi, data langsung dimuat saat halaman dibuka.

📡 Endpoint API GET (Code.gs)

Apps Script doGet(e) menerima parameter ?action=:

1. Leaderboard — Semua Siswa

GET ?action=leaderboard

Response: { status: "ok", leaderboard: [...] } — array objek siswa dengan total kuis, rata-rata skor, total aktivitas, jumlah pertemuan.

2. Summary — Data Satu Siswa

GET ?action=summary&name=Andi

Response: { status: "ok", data: {...} } atau { status: "not_found", data: { kuis: [...], aktivitas: [...] } }

3. Pertemuan — Semua Siswa di Satu Pertemuan

GET ?action=pertemuan&sheet=Pertemuan 1

4. Aktivitas — Log Aktivitas Siswa

GET ?action=aktivitas&sheet=Pertemuan 1&name=Andi

5. List — Daftar Semua Pertemuan

GET ?action=list

⚡ Optimasi Dashboard Siswa

1. Parallel Fetch

Gunakan Promise.all() untuk fetch leaderboard dan summary sekaligus — mengurangi waktu load hingga 50%:

const [lbRes, sumRes] = await Promise.all([
  fetch(BASE + '?action=leaderboard'),
  fetch(BASE + '?action=summary&name=' + encodeURIComponent(nama))
]);
const leaderboard = await lbRes.json();
const summary = await sumRes.json();

2. Lazy Load Pertemuan

Jangan fetch semua pertemuan sekaligus. Muat daftar pertemuan saat tab diklik, lalu fetch detail saat tombol pertemuan ditekan:

// Hanya fetch list saat tab aktif
if (tab === 'pertemuan' && pertemuanList.length === 0) {
  const res = await fetch(BASE + '?action=list');
  const data = await res.json();
  setPertemuanList(data.pertemuan);
}

// Fetch detail saat tombol diklik
async function loadDetail(namaPertemuan) {
  const [q, a] = await Promise.all([
    fetch(BASE + '?action=pertemuan&sheet=' + encodeURIComponent(namaPertemuan)),
    fetch(BASE + '?action=aktivitas&sheet=' + encodeURIComponent(namaPertemuan) + '&name=' + encodeURIComponent(nama))
  ]);
}

3. Cache di localStorage

Simpan data di localStorage untuk mengurangi request berulang:

function cacheGet(key, fallback) {
  try { return JSON.parse(localStorage.getItem(key)) || fallback; }
  catch { return fallback; }
}
function cacheSet(key, val) {
  try { localStorage.setItem(key, JSON.stringify(val)); } catch {}
}

// Gunakan
const cached = cacheGet('lb_data', null);
if (cached && Date.now() - cached.time < 300000) {
  // Gunakan cache (5 menit)
  renderLeaderboard(cached.data);
} else {
  // Fetch baru
  const res = await fetch(BASE + '?action=leaderboard');
  const data = await res.json();
  cacheSet('lb_data', { data: data.leaderboard, time: Date.now() });
}

4. Error Handling yang Robust

try {
  const res = await fetch(url);
  if (!res.ok) throw new Error('HTTP ' + res.status);
  const data = await res.json();
} catch (err) {
  // Tampilkan pesan ramah, bukan error teknis
  showError('Gagal memuat data. Periksa koneksi internet Anda.');
  console.error('[dashboard]', err);
}

👨‍🏫 Dashboard Dosen (Lecturer Console)

Gunakan <quiz-dashboard-lite2 view-mode="lecturer"> atau <lecturer-console> untuk mode dosen:

<quiz-dashboard-lite2
  apps-script-url="https://script.google.com/macros/s/YOUR_ID/exec"
  forum-api-url="https://script.google.com/macros/s/YOUR_FORUM_ID/exec"
  view-mode="lecturer"
  sheet-name="Pertemuan 1">
</quiz-dashboard-lite2>

Fitur Mode Dosen

  • Lihat semua siswa — Daftar siswa dengan skor dan status kelulusan
  • Generate soal — Buat soal kuis baru langsung dari console
  • Input nilai UTS/UAS — Set nilai akhir untuk komponen gradebook
  • Threshold kehadiran — Ubah kriteria minimum kehadiran
  • Bobot nilai — Sesuaikan persentase kehadiran, kuis, UTS, UAS

Optimasi Dashboard Dosen

1. Gunakan GET untuk Read, POST untuk Write

Dosen membaca data siswa via GET (sama seperti dashboard siswa). Perubahan threshold/bobot via POST ke Apps Script yang sama.

2. Real-time dengan Polling

// Refresh data setiap 30 detik
setInterval(async () => {
  const res = await fetch(BASE + '?action=leaderboard');
  const data = await res.json();
  renderLeaderboard(data.leaderboard);
}, 30000);

3. Export ke Spreadsheet

Gunakan lecturer-console untuk generate laporan PDF atau export ke Google Sheets baru.
