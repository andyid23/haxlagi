🔔 Notif Element — Komponen Notifikasi

Elemen <notif-element> adalah komponen notifikasi sederhana berbasis vanilla Web Component. Cocok untuk menampilkan pesan notifikasi dengan berbagai tipe di situs HAXcms.

🧪 Demo Langsung

📋 Atribut yang Didukung

AtributTipeDeskripsiDefault
typeStringTipe notifikasi: info, success, warning, errorinfo
messageStringPesan yang ditampilkan—
durationNumberDurasi tampil dalam milidetik (0 = tidak auto-hide)5000
visibleBooleanStatus tampil notifikasifalse

🖥️ Cara Penggunaan

HTML Deklaratif

<notif-element 
  type="success" 
  message="Data berhasil disimpan!" 
  duration="3000"
  visible="true">
</notif-element>

JavaScript API

// Membuat elemen notifikasi
const notif = document.createElement('notif-element');
notif.setAttribute('type', 'success');
notif.setAttribute('message', 'Data berhasil disimpan!');
notif.setAttribute('duration', '3000');
document.body.appendChild(notif);

// Method: show() dan hide()
notif.show();   // Tampilkan notifikasi
notif.hide();   // Sembunyikan notifikasi

Event Listener

const notif = document.querySelector('notif-element');

notif.addEventListener('notif-show', (e) => {
  console.log('Notifikasi ditampilkan:', e.detail);
});

notif.addEventListener('notif-hide', (e) => {
  console.log('Notifikasi disembunyikan:', e.detail);
});

🛠️ Fitur

  • 4 Tipe Notifikasi: info, success, warning, error
  • Auto-hide: Notifikasi otomatis sembunyi setelah durasi tertentu
  • Closable: Tombol × untuk menutup manual
  • Animasi Transisi: Fade-in dan slide-up yang smooth
  • Aksesibilitas: aria-label pada tombol close
  • Shadow DOM: Style terisolasi, tidak bentrok dengan CSS halaman
  • Custom Events: notif-show dan notif-hide

📱 Responsif

Notifikasi secara otomatis menyesuaikan lebar maksimum 100% dari container. Cocok untuk mobile dan desktop.
